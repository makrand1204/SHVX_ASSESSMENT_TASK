# SHVX_ASSESSMENT
SOCIAL MEDIA USER ACTIVITY
PROJECT OVERVIEW
This project demonstrates an end-to-end data analysis and machine learning workflow using a real-world dataset. The goal is to clean the data, extract meaningful insights through exploratory data analysis (EDA), and build and compare multiple machine learning models to evaluate their performance.

The project is designed to reflect industry-standard practices and is suitable as a portfolio project for Data Analyst / Data Science fresher roles.

TECHNOLOGIES AND TOOLS USED

Python

Pandas & NumPy – Data manipulation and cleaning

Matplotlib & Seaborn – Data visualization

Scikit-learn – Machine learning models and evaluation

PyCharm – Development environment

Git & GitHub – Version control and project hosting



HOW TO USE THIS PROJECT 
1. Clone the repository
git clone https://github.com/your-username/your-repo-name.git

2. Install dependencies
pip install -r requirements.txt

3. Run the project
python main.py


--Ensure the dataset file is placed in the appropriate directory before running the script.
